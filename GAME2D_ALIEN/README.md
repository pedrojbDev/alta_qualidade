# Game 2D: Alien Invasion

Projeto realizado em aula durante a disciplina de Alta Qualidade de Software.

## Como executar

Com o Pygame instalado, execute a partir da raiz do repositório:

```bash
python GAME2D_ALIEN/src/alien_invasion.py
```

Use as setas esquerda e direita para mover a nave e a barra de espaço para atirar.
